# Kishore Kumar — Show Director / FOH Director

Single-page portfolio site. Static HTML, no build step.

- `index.html` — the whole page (CSS and JS inline)
- `assets/` — photos, showreel clip and the social share card

## Publishing on GitHub Pages

1. Create a public repository and upload every file in this folder, keeping the `assets/` folder.
2. Repository → **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)` → **Save**.
3. The site goes live at `https://<username>.github.io/<repository-name>/` within a minute or two.

## Updating contact details

Phone, email and Instagram sit near the bottom of `index.html`, in the section marked `id="contact"`.
